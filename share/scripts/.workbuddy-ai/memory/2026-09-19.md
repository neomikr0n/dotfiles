# 2026-09-19

## genymotion-open.sh — arreglado el "no va al extremo izquierdo"

Causa: el script usaba la sintaxis clásica de `hyprctl dispatch`, que Hyprland 0.56 ya no
acepta (el argumento se evalúa como Lua). Los tres puntos rotos y su equivalente nuevo:

- `dispatch focuswindow address:A` → `hl.dsp.focus({ window = "address:A" })`
- `dispatch swapwindow l` → `hl.dsp.window.swap({ direction = "l" })` (actúa sobre la ventana activa)
- `dispatch resizewindowpixel exact W H,address:A` → `hl.dsp.window.resize({ x = W, y = H, window = "address:A" })`

Cambios en el archivo: helpers `lua_focus()`, `lua_swap_left()`, `lua_resize()` (concentran el
escapado de comillas) + bloque de comentarios documentando la ruptura de API. El `hyprctl --batch`
se mantiene (acepta Lua) para conservar la atomicidad foco+swap del bucle.

Verificado en vivo: con el emulador en x=2107, las funciones del script lo devolvieron a x=2 y
767x1436. El fallo era silencioso porque el script solo imprimía un warning y continuaba.
